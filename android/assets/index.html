Tutorial: Connecting to Gemini

1
Trust Local Certificate (One-Time)

Because browser security requires HTTPS when connecting from Google Gemini, tap the button below to download the TLS certificate, then install it on your device:

Download .crt Certificate

On Android: Go to Settings › Security › More security settings › Encryption & credentials › Install a certificate › CA certificate and select dexcards-ca.crt.
On PC: Double click the downloaded .crt and choose Install Certificate › Trusted Root Certification Authorities.

2
Register Server in Google Gemini

In Google Gemini (gemini.google.com) or Google AI Studio:

1. Open Settings › Custom Tools / Model Context Protocol.
2. Click Add Server.
3. Paste the Gemini MCP URL:

https://10.58.147.133:8443/mcp

4. Click Connect. Gemini will negotiate the protocol handshake and discover all 14 tools!

3
Connecting to Claude Desktop or Cursor

If using Claude Desktop or Cursor, paste this snippet into your claude_desktop_config.json: 

{
  "mcpServers": {
    "dexcards": {
      "url": "https://10.58.147.133:8443/sse"
    }
  }
}
4
